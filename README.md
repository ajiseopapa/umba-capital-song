# 움바 움바 세계수도송 🌍

"움바 움바 움바리 움바" 4박자 후렴에 맞춰 나라의 수도를 맞히는 리듬 퀴즈 게임.
빌드 없는 단일 HTML 파일이고, 소리는 Web Audio API로 실시간 합성합니다(외부 파일 0개).

## 사운드

원곡 세계수도송의 멜로디를 쓰지 않은 **자작 반주**입니다. 후렴 문구만 브라우저 음성합성으로 부릅니다.

- 반주: 마림바 훅 + 브라스 스탭 + 손뼉/셰이커/탬버린, Am-F-C-G 4마디 순환, 8분음표 스윙 8%
- 챈트: 두 마디 한 세트로 `움바 움바 움바리 움바` → `움바 움바 세계수도송` (한국어 보이스 자동 선택, 템포에 맞춰 속도 조절)
- 마스터에 리미터를 걸어 악기가 겹칠 때 찌그러지지 않게 했습니다
- HUD의 🗣️ 로 챈트만 끄고 반주만 들을 수 있습니다

## 모드

| 모드 | 방식 | 제한 |
|---|---|---|
| 🔤 글자 고르기 | 보기 4개 중 선택 (키보드 `1`~`4` 지원) | 8박자 |
| 🎤 목소리로 말하기 | 보기 없이 수도를 직접 발음 | 12박자 (절반 지나면 첫 글자 힌트) |

## 규칙

- 나라 74개, 오답 보기는 같은 대륙에서 우선 출제
- 점수 = 100 + 남은 박자 보너스 + 콤보 보너스
- 5개 맞힐 때마다 템포 +8 BPM (96 → 최대 168)
- 하트 3개, 오답이나 시간초과 시 1개 차감
- 최고 점수는 모드별로 브라우저에 저장

## 음성 모드 참고

- Web Speech API를 사용하므로 **Chrome / Edge**에서 동작하고 마이크 권한이 필요합니다.
- 받아쓰기 오차를 감안해 편집거리 기반 퍼지 매칭 + 통용 표기 사전을 씁니다.
  ("워싱톤 디씨", "부에노스 아이레스", "음... 서울!" 등도 정답 처리)
- 마이크가 반주를 덜 듣도록 음성 모드에서는 반주 볼륨을 낮춥니다. 이어폰 권장.

## 로컬 실행

```bash
open index.html
```

음성 모드는 `file://`에서 마이크가 차단될 수 있으니 로컬 서버로 여는 것을 권장합니다.
